# จดจ่าย

แอปจดรายรับ–รายจ่ายแยกตามบัญชีธนาคาร รอบเดือนนับจากวันเงินเดือนออก (ค่าเริ่มต้นวันที่ 25 เลื่อนไปวันทำการก่อนหน้าถ้าตรงวันหยุด)

- Nuxt 4 (ปิด SSR) ขึ้น GitHub Pages ผ่าน GitHub Actions เมื่อ push เข้า `main`
- ข้อมูลเก็บใน IndexedDB ของเครื่อง
- โลโก้ธนาคารจาก [omise/banks-logo](https://github.com/omise/banks-logo) (MIT)

```bash
npm install
npm run dev     # http://localhost:3000
npm test
```
